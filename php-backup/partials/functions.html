⚠️ Important: This file is not executed by the PHP application. The live site loads functions.php to escape output, build URLs, and generate cache-busted asset links. The examples below show what each function would output given a specific input and a base URL of http://localhost/portfolio.

e() — Escape HTML Output Security

function e(?string $value): string

Safely escapes a string for HTML output by converting special characters to HTML entities. Prevents XSS (cross-site scripting) attacks when rendering user-supplied or dynamic data.

Parameter $value — The string to escape. null is treated as an empty string.
Returns An HTML-safe string encoded with ENT_QUOTES | ENT_SUBSTITUTE in UTF-8.
Flags used ENT_QUOTES — escapes both double and single quotes.
ENT_SUBSTITUTE — replaces invalid code sequences with a Unicode replacement character.
e('Hello & welcome')
→ 'Hello &amp; welcome'

e('<script>alert(1)</script>')
→ '&lt;script&gt;alert(1)&lt;/script&gt;'

e('It\'s "quoted"')
→ 'It&#039;s &quot;quoted&quot;'

url() — Build Absolute URLs Navigation

function url(string $path = ''): string

Builds an absolute URL using the site's base URL (stored in $GLOBALS['__site_base_url']). Passes through anchors, empty strings, and fully-qualified URLs unchanged.

Parameter $path — A relative path (about.php), anchor (#section), or absolute URL.
Returns A fully-qualified URL rooted at the site's base URL, or the original value for pass-through cases.
Pass-through rules • Empty string → returned as-is.
• Starts with # → returned as-is (anchor link).
• Matches http://, https://, or // → returned as-is.
// Base URL: http://localhost/portfolio
url('about.php')
→ 'http://localhost/portfolio/about.php'

url('blog/post.php')
→ 'http://localhost/portfolio/blog/post.php'

url('#section')
→ '#section' // passthrough

url('https://example.com')
→ 'https://example.com' // passthrough

url('')
→ '' // passthrough

asset() — Asset URLs with Cache-Busting Performance

function asset(string $path): string

Returns a public URL for a static asset (CSS, JS, image) and appends a cache-busting query string based on the file's last-modified time. This forces browsers to fetch the latest version whenever the file changes.

Parameter $path — Relative path to the asset, e.g. assets/css/home.css.
Returns A full URL via url(), with ?v=xxxxxx appended if the file exists on disk.
Version string The last 6 digits of the file's filemtime() Unix timestamp.
// File: /portfolio/assets/css/home.css (last modified 1712345678)
asset('assets/css/home.css')
→ 'http://localhost/portfolio/assets/css/home.css?v=345678'

// File does not exist on disk
asset('assets/img/missing.png')
→ 'http://localhost/portfolio/assets/img/missing.png' // no version

is_current() — Active Navigation State UI

function is_current(string $slug, string $current): string

Compares a navigation slug against the current page's slug. Returns 'active' if they match, or an empty string otherwise. Typically used to add an active CSS class to the current menu item.

Parameter $slug — The navigation item's slug (e.g. 'about').
Parameter $current — The current page's slug (e.g. $page['slug']).
Returns 'active' if the slugs match, otherwise '' (empty string).
// Current page slug: 'about'
is_current('about', 'about')
→ 'active'

is_current('projects', 'about')
→ ''
